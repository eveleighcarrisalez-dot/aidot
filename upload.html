上传图片到 images/（需密码与 PAT）

说明：上传会把图片写入仓库的 images/ 目录。为了安全，页面要求两个东西：您设置的上传密码（页面会在本地将密码哈希后比对），以及一个用于写入仓库的 GitHub Personal Access Token (PAT)。PAT 不会被保存到仓库，它仅用于当前浏览器会话并直接用于 GitHub API。

说明与安全提示

  • 如果您希望把密码哈希写入仓库以供所有用户验证，您可以先使用“在本地生成并保存密码哈希”功能得到哈希值，然后将该哈希粘贴到仓库里的配置文件（我也可以代为提交）。
  • 本页会在上传后显示图片的 raw 和 Pages 链接，您可以直接复制使用。
  • 请只使用权限最小的 PAT（仅需 repo:contents 写权限）。
